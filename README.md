# سيوف الممالك ⚔️

لعبة حرب استراتيجية من منظور فوقي، مصمّمة للجوال أولاً، يقود فيها الذكاء الاصطناعي الممالك المعادية.
العصر قديم: **الممالك الثلاث في الصين (208م)** أو **الفتوحات الأموية على الثغور (715م)**.
القتال التحام بالرماح والسيوف والخيل، مع أسلحة بعيدة المدى قديمة: الأقواس والقوس المتكرر، والخيّالة الرماة، والمنجنيق.

## التشغيل

اللعبة ملفات ثابتة بلا أي بناء أو مكتبات خارجية:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000 على الهاتف أو الحاسوب
```

للنشر: فعّل **GitHub Pages** على المستودع وافتح الرابط من الجوال، ثم «أضف إلى الشاشة الرئيسية». يُفضَّل الوضع الأفقي.

## الحملة

- **الحركة بالنقاط:** لكل جيش 4 نقاط حركة (🥾).
  - الكلفة حسب أرض الوجهة: السهول والأنهار والسواحل 2، الغابات والتلال والصحراء 3، الجبال والممرات 4.
  - الطرق المعبّدة تخفّض الكلفة، والشتاء يُغلق الممرات.
  - يمكن التحرك خطوتين في أرضك ثم الحصار أو الانضمام لجيش، لكن معركة واحدة فقط في الدور.
- **القادة وحدودهم:**
  - كل قائد يقود 8 وحدات، ويمكن لعدة قادة البقاء في مدينة واحدة.
  - يمكنك تقسيم الجيش بأعداد دقيقة (مثلاً 250 من 600) ليذهب جزء مع قائد جديد، أو نقل وحدات بين القادة.
- **الإمداد والازدحام:**
  - لكل مدينة سعة إمداد.
  - الجيوش فوقها تمرض وتهرب وتُنقص الولاء والدخل.
  - خارج أرضك تأكل الجيوش أكثر، والصحراء أكثر.
- **القوى البشرية:**
  - التجنيد والتعويض يستهلكان رجال المدينة (👥) الذين يتجددون ببطء.
  - الخسائر لها ثمن، ولا يعود جيش كامل بلا كلفة.
- **الاحتلال:**
  - المدينة المحتلة حديثاً مضطربة: دخل قليل، ولا تجنيد نظامي (المرتزقة فقط)، والحامية تبدأ من الصفر.
  - الجيوش المهزومة داخلها تخرج بممر آمن أو تلقي السلاح.
- **الاقتصاد:**
  - الضرائب (دخل مقابل ولاء)، رواتب القادة، وكلفة إدارة الجيوش الزائدة.
  - المرتزقة، ومشاريع المدن (أسوار حتى القلعة العظمى، أسواق، مخازن، طرق، احتفالات).
  - الفساد في الإمبراطوريات الكبيرة.
- **الحصار:**
  - الكبش والسلالم بعد دور، وبرج الحصار بعد دورين، والمنجنيق يفتح الثغرات.
  - التجويع يُسقط المدن، وقد يعرض المحاصِر الأمان على المدينة الجائعة.
  - تعزيز جيش محاصِر يتم بالتحرك الطبيعي إليه.

## القادة

لكل قائد تاريخي سمة تغيّر نظاماً مختلفاً، وأحياناً عيب:

| السمة | أثرها |
|---|---|
| داهية | الالتفاف أقوى ونقطة أوامر إضافية |
| شجاع | معنويات الجيش +15 |
| فارس | انقضاض الخيالة أقوى وأسرع |
| رامٍ ماهر | رماية أقوى وسهام أكثر |
| مهندس حصار | معدات فورية وضرب أسوار أقوى |
| صامد | دفاع المدن ومعنوياته |
| إداري | دخل وولاء المدينة التي يقيم فيها |
| خبير تموين | نصف الطعام وبلا استنزاف |
| سريع | نقطتا حركة إضافيتان |
| ابن الجبال | الجبال والممرات لا تبطئه |
| ابن الصحراء | يعبر الصحراء بلا عطش |
| ربّان | يعبر الطرق المائية |
| قائد نخبة | يتيح وحدة النخبة لحضارته |

- **العيوب:** متهوّر، متردد، قاسٍ، طمّاع، متكبّر، متقلّب.
- **الرتب:** يرتقي القادة بالمعارك (★★★).
- **الأسر:** قد يقع القادة في الأسر. عندها يمكنك إطلاق سراحهم، أو طلب فدية، أو التبادل، أو ضمّهم، أو النفي، أو الإعدام.
- **ثمن الإعدام:** ينهار سمعتك، وتتلقى ثأراً ممن أعدمت قائده، وتضطرب مدنه، وقد يظهر منتقم.

## الدبلوماسية والعالم

- الحرب والصلح والأحلاف (وقد تُفضّ)، والتجارة، والمصاهرة، والجزية الدورية، وتمويل الحلفاء.
- الجواسيس: الاستطلاع، والتحريض، والتخريب.
- مهاجمة مملكة في سلام ممكنة، لكنها إعلان حرب بعواقب على السمعة والحلفاء.
- للذكاء الاصطناعي أهداف: التوسع، استعادة المدن المفقودة، انتهاز المدن الضعيفة، الدفاع، والتحالف ضد المملكة المتعاظمة. يكسر الجمود حين يطول السلام.
- **تقرير الجولة** مقسّم إلى: عسكري، سياسي، اقتصادي، داخلي. **لوحة الممالك** تعرض معلومات دقيقة أو تقديرية أو مجهولة حسب علاقاتك وجواسيسك.

## المعركة

- **قبل المعركة:** التمركز، وخطة المعركة (متوازنة، هجوم كاسح، دفاع صلب، كمين، استنزاف، كسر الجناح). بعض الخطط أقوى حسب سمة القائد.
- **أثناء المعركة:** أوامر القائد بنقاط محدودة تتجدد: هجوم شامل، اثبتوا، تركيز الرماة، التفاف الفرسان، تراجع منظم، اقتحام الأسوار.
- **الأرض:**
  - التلال: +25٪ للأعلى.
  - المخاضات: تُضعف العابر.
  - الغابات: تُخفي وتحجب السهام وتعيق الخيالة.
  - السهول: ميدان الانقضاض.
  - الصحراء: تُنهك غير المعتادين.
  - الممرات الجبلية: تُلغي التفوق العددي.
- **الإرهاق والمعنويات:** الركض والقتال يُتعبان، والاحتياط الطازج يحسم. الجيوش تنكسر وتفرّ قبل الإبادة، وسقوط القائد يزلزلها.
- **الأسوار:**
  - سور خارجي لا يُعبر إلا من البوابة أو ثغرة أو سلّم أو برج حصار.
  - خلفه ممشى يقف عليه الرماة المدافعون.
- **الاحتياط:** الجيوش الكبيرة تُدخل وحداتها الزائدة تباعاً.

## التحكم باللمس

- اضغط وحدة ثم الأرض للتحرك، أو العدو للهجوم.
- اضغط مطوّلاً واسحب لاتجاه الصف.
- إصبعان للتكبير.
- في الخريطة: زر التصغير (—) يُبقي وضع اختيار الوجهة فعّالاً مع شريط صغير.
